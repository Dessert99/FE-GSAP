> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development for page-local tasks. Steps use checkbox (`- [ ]`) syntax for tracking. The user-approved execution override allows three independent page workers in parallel; root owns integration and review.

**Goal:** Plugin P21~P46 26개 페이지와 119개 canonical source를 구현해 GSAP 학습 프로그램을 page 86/86, canonical 364/364 상태로 만든다.

**Architecture:** `plugin-learning-curriculum.md`의 page identity와 source ownership을 변경하지 않는다. 세 page-local worker가 서로 다른 slug를 병렬 준비하고, root가 P21→P46 순서로 route, full TypeScript/Vite/Storybook, handoff release와 page commit을 하나씩 통합한다.

**Tech Stack:** React 19, TypeScript 6, GSAP 3.15, `@gsap/react`, Vite 8, Storybook 10, CSS, Markdown handoff

## Global Constraints

- 구현 전 `AGENTS.md`, `docs/project-structure.md`, `docs/workflows/README.md`와 연결 계약, `current-status.md`, master inventory, plugin curriculum을 읽는다.
- 공식 canonical은 rendered와 raw/installed source/types를 각각 최소 두 번 대조하고 item-level `sourceManifest`와 `coverageMap`을 먼저 고정한다.
- 공식 문서가 침묵하며 틀리면 학습 오류가 되는 동작만 설치본으로 probe하고 공식 사실과 분리한다.
- Page TSX는 조립, `sections/`는 학습 단위, `examples/` runtime은 실제 GSAP 호출과 lifecycle을 소유한다.
- controls, normalized descriptor, 실제 call, snapshot과 displayed code는 같은 runtime state에서 파생한다.
- `examples/`와 runtime source의 모든 선언·실행 단계에 역할과 이유를 설명하는 한 줄 한국어 주석을 둔다.
- continuous input/progress/velocity/text intermediate 값은 live region 밖에 두고 requested snapshot과 lifecycle result만 알린다.
- Worker는 배정된 content folder, handoff와 ignored report만 수정한다. `routes.ts`, 프로그램 문서, 공용 UI, 전역 CSS, package, Git은 root만 수정한다.
- 모든 worker가 source 쓰기를 멈춘 뒤 root가 full TypeScript, Vite, Storybook을 실행한다.
- 자동화 테스트 파일, runner, test dependency를 추가하지 않는다. browser keyboard/focus, 실제 reduced-motion, 320/390 layout, 실제 controls만 `DEFERRED`다.
- PixiJS는 설치되지 않았으므로 P30은 fake runtime/dependency 없이 static executable boundary로 만든다.
- ScrollSmoother와 document-wide integration API는 host app을 자동으로 hijack하지 않는다. 안전하게 격리할 수 없는 global call은 source-backed static lifecycle representation으로 가르친다.
- 아직 등록되지 않은 prerequisite/follow-up route는 text-only boundary로 두고 root integration 시 링크한다.
