> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development for page-local tasks. Steps use checkbox (`- [ ]`) syntax for tracking. The root integrator owns shared files, verification, and Git.

**Goal:** Plugin P07~P20의 14개 학습 페이지를 공식 source 전체 coverage, 학습형 재구성, runtime/display 동기화와 페이지별 release 증거를 갖춘 상태로 구현한다.

**Architecture:** 기존 `2026-08-08-gsap-plugin-wave-delivery-design.md`의 세 페이지 병렬 준비·순차 통합 방식을 반복한다. Worker는 하나의 page-local content 폴더와 handoff만 쓰고, root가 P07부터 P20까지 `src/app/routes.ts`, 전체 TypeScript/Vite/Storybook, release 갱신과 Git commit을 순서대로 소유한다.

**Tech Stack:** React 19, TypeScript 6, GSAP 3.15, `@gsap/react`, Vite 8, Storybook 10, CSS, Markdown handoff

## Global Constraints

- 구현 전 `AGENTS.md`, `docs/project-structure.md`, `docs/workflows/README.md`와 연결된 다섯 계약, `current-status.md`, master inventory, plugin curriculum을 읽는다.
- 공식 canonical은 rendered 페이지와 raw/installed source를 최소 두 번 대조하고 heading, signature, parameter, return, note, warning, example을 item 단위로 기록한다.
- 페이지마다 item-level `sourceManifest`와 `coverageMap`을 먼저 고정하며 range나 묶음 ID로 canonical을 대신하지 않는다.
- Page TSX는 조립, `sections/`는 학습 단위, `examples/`의 실행 source는 실제 GSAP 호출과 lifecycle을 소유한다.
- controls, 정규화 descriptor, 실제 호출, 관찰 snapshot과 표시 코드는 같은 runtime state에서 파생한다.
- `examples/`와 `use*Animation.ts`/`use*Runtime.ts`의 선언·실행 단계에는 역할과 이유를 설명하는 한 줄 한국어 주석을 둔다.
- 연속 좌표·속도·progress 값은 live region 밖에 두고 press/release/command/result 같은 이산 상태만 알린다.
- 자동화 테스트 파일, 테스트 러너, 테스트 전용 의존성을 추가하지 않는다. 검증은 source/coverage 스크립트, `npx tsc --noEmit`, Vite, Storybook과 승인된 browser 유예로 수행한다.
- Worker는 배정된 content 폴더, page handoff, 배정된 SDD report만 수정한다. route, 프로그램 문서, 공용 UI, 전역 CSS, package 파일과 Git은 root만 수정한다.
- Worker가 모두 쓰기를 멈춘 뒤에만 root가 전체 build를 실행한다.
- 브라우저 키보드·focus, 실제 reduced-motion, 320/390px layout, 실제 control 조작만 `DEFERRED`로 남긴다.
- 아직 등록되지 않은 후속 페이지는 내부 링크로 만들지 않고 텍스트 경계로 남긴다.
- P10 EaselPlugin은 실제 CreateJS dependency가 현재 없으므로 dependency를 추가하지 않는다. 공식 integration contract와 executable-boundary diagram을 정적으로 가르치고 `runtimeSource: none`을 명시한다.
- P20은 curriculum상 P21 개념을 선행 지식으로 요구하지만 P21 route가 아직 없으므로 SVG path data 전제를 페이지 안에서 짧게 정의하고 P21은 텍스트 경계로만 남긴다.
