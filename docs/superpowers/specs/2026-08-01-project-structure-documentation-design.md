# 프로젝트 구조 문서화 설계

## 변경 범위

- `docs/project-structure.md`에 현재 프로젝트의 주요 폴더와 파일을 트리로 정리한다.
- 각 항목에는 역할을 이해하는 데 필요한 짧은 설명만 붙인다.
- `node_modules`, `dist`, Git 내부 파일, 임시 파일은 제외한다.
- `AGENTS.md`의 필수 참조 순서에 구조 문서를 추가한다.
- `docs/progress.md`에 문서화 완료 상태를 기록한다.

## 검증

- 문서의 경로가 실제 저장소 구조와 일치하는지 확인한다.
- `AGENTS.md`에서 구조 문서 링크를 바로 찾을 수 있는지 확인한다.
