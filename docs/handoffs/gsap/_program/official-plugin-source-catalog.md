## Dependency, registration, environment, and related-page note keys

- `D-INFRA` — Plugins overview. Load/import a plugin before use; register it with `gsap.registerPlugin(...)` once before use. Registration protects plugins from bundler tree-shaking. Re-registering is harmless but unnecessary. Related: Installation and `gsap.registerPlugin()` official API.
- `D-INSTALL` — Official install helper/source for script tags, npm/yarn and module imports. Current page says to use GSAP 3.13+; relate every separately loaded plugin to its entry point and registration step. Environment-specific CDN/npm/SSR/bundler details live here.
- `D-CORE` — Internal core plugin: automatically included in GSAP core and does not need separate loading or `gsap.registerPlugin()`. Ownership overlap is intentional because the Plugins overview presents it under Included in GSAP's Core.
- `D-REACT` — Requires React, `gsap`, and `@gsap/react`; register `useGSAP`. Client-component boundary is required for React Server Components; the hook uses an isomorphic layout-effect fallback and Context cleanup. Related: `gsap.context()`, `revert()`, React useful patterns/advanced techniques.
- `D-SCROLLTRIGGER` — Load/import and register ScrollTrigger separately from core. Browser scroll/DOM layout is measured at creation/refresh; React requires cleanup. Related: ScrollSmoother, Observer/`ScrollTrigger.observe()`, `gsap.matchMedia()`, common ScrollTrigger mistakes, Installation.
- `D-SCROLLSMOOTHER` — Requires ScrollTrigger; load/import and register both. Browser-only vertical native-scrolling enhancement; uses wrapper/content and owns a main ScrollTrigger. Preserve native accessibility semantics and cleanup. Related: ScrollTrigger and Installation.
- `D-SCROLLTO` — Load/import and register ScrollToPlugin separately. Browser/window or element scrolling; auto-kill and scroll-proxy interactions must be considered. Related: ScrollTrigger/ScrollSmoother and Installation.
- `D-DRAWSVG` — Load/import and register DrawSVGPlugin separately. Requires SVG stroke-capable geometry; percentage/length behavior depends on rendered SVG geometry. Related: SVG `getTotalLength()`, MotionPathPlugin, Installation.
- `D-MORPHSVG` — Load/import and register MorphSVGPlugin separately. Requires compatible SVG shape/path geometry; conversion, origin, winding/shape-index, render/update hooks and target replacement are page-owned caveats. Related: MotionPathPlugin utilities and Installation.
- `D-MOTIONPATH` — Load/import and register MotionPathPlugin separately. Works with path strings, SVG paths and point arrays; coordinate/alignment transforms and raw-path utilities are shared by MorphSVG/MotionPathHelper. Related: MotionPathHelper, MorphSVG, Installation.
- `D-MOTIONPATHHELPER` — Requires MotionPathPlugin; load/import and register both. Browser DOM/SVG editor with pointer/keyboard editing and temporary controls; kill/cleanup editor DOM. Related: MotionPathPlugin and Installation.
- `D-FLIP` — Load/import and register Flip separately. Browser DOM layout measurement: capture state before the DOM/layout change, then animate from/to it; cleanup interrupted/in-progress flips. Related: `gsap.context()`, absolute positioning/nesting guidance, Installation.
- `D-DRAGGABLE` — Load/import and register Draggable separately. Browser pointer/touch/mouse and DOM geometry; InertiaPlugin is the related momentum/throw dependency when inertia behavior is requested. Kill/disable listeners during cleanup. Related: Inertia, Observer, Installation.
- `D-INERTIA` — Load/import and register InertiaPlugin separately. Commonly paired with Draggable; velocity tracking and bounds/end prediction need numeric/property contracts. Related: VelocityTracker, Draggable, Installation.
- `D-VELOCITYTRACKER` — Owned by InertiaPlugin. Track/untrack target properties before relying on velocities and remove tracking during cleanup. Related: InertiaPlugin and Draggable.
- `D-OBSERVER` — Load/register Observer when standalone; if ScrollTrigger is already loaded, Observer is included inside it and `ScrollTrigger.observe()` is equivalent to `Observer.create()`. Browser wheel/touch/pointer/scroll events; disable/kill listeners on cleanup. Related: ScrollTrigger normalizeScroll/observe and Installation.
- `D-SPLITTEXT` — Load/import and register SplitText separately. Browser DOM/text measurement; fonts, re-splitting/responsive layout, accessibility, masks and `revert()` cleanup are environment/lifecycle boundaries. Related: text animation helpers, `gsap.context()`, Installation.
- `D-SCRAMBLETEXT` — Load/import and register ScrambleTextPlugin separately. Text-content replacement behavior; preserve accessible readable text and cleanup/reversion in framework lifecycles. Related: SplitText, TextPlugin, Installation.
- `D-TEXT` — Load/import and register TextPlugin separately. Replaces/interpolates text or element content; delimiter/padding/class behavior and accessible final content are page boundaries. Related: ScrambleText, SplitText, Installation.
- `D-PHYSICS2D` — Load/import and register Physics2DPlugin separately. Time-based 2D velocity/angle/gravity/friction property tween; not a collision engine. Related: PhysicsProps and Installation.
- `D-PHYSICSPROPS` — Load/import and register PhysicsPropsPlugin separately. Applies velocity/acceleration/friction independently per property; not a collision engine. Related: Physics2D and Installation.
- `D-GSDEVTOOLS` — Load/import and register GSDevTools separately. Development/debug UI that controls GSAP animations; browser DOM only and normally not part of production runtime. Destroy/cleanup tool instances. Related: Timeline/Tween controls and Installation.
- `D-EASEL` — Load/import and register EaselPlugin separately and load EaselJS/CreateJS. Targets EaselJS display objects/canvas integration, so CreateJS availability and render/update lifecycle are required. Related: Installation.
- `D-PIXI` — Load/import and register PixiPlugin separately, call/register the active PIXI namespace when required, and load PixiJS. Version/rendering/color/transform contracts belong to the integration boundary. Related: `registerPIXI()` and Installation.
- `D-CSSRULE` — Current official sitemap technical page, but omitted from the current Plugins overview categories; record official category as uncategorized rather than guessing. Load/import and register CSSRulePlugin separately. It proxies CSSStyleRule declarations and has browser stylesheet/CORS access caveats. Related: CSSPlugin and Installation.
- `D-EASING` — Core eases are included. RoughEase, SlowMo and ExpoScaleEase ship together in EasePack; CustomEase, CustomBounce and CustomWiggle are separate plugin files. Related: Installation and `gsap.parseEase()`/`registerEase()`.
- `D-CUSTOMEASE` — Load/import and register CustomEase separately. It accepts SVG path/control-point data and can produce/inspect custom ease data. Dependency owner for CustomBounce and CustomWiggle. Related: Easing visualizer and Installation.
- `D-CUSTOMBOUNCE` — Requires CustomEase; load/import and register both CustomEase and CustomBounce. Optional squash ease is a related generated ease. Related: CustomEase, Easing visualizer, Installation.
- `D-CUSTOMWIGGLE` — Requires CustomEase; load/import and register both CustomEase and CustomWiggle. Wiggle type/template and randomized curves are core configuration boundaries. Related: CustomEase, Easing visualizer, Installation.
- `D-EASEPACK` — ExpoScaleEase, RoughEase and SlowMo are not core eases; they are packaged together in EasePack to minimize file size. Load/import EasePack (or its exports) and register as documented for the environment. Related: Easing visualizer and Installation.
- `D-STEPPEDEASE` — Core-included ownership overlap: `steps(n)` is presented under core eases while SteppedEase retains a nested Eases technical page. No separate EasePack dependency. Related: Easing visualizer and Installation.
